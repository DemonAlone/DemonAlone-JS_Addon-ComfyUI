### Formatting Rules
1. **Remove consecutive spaces** (e.g., `hello  world` → `hello world`)
2. **Collapse repeated commas/periods** (e.g., `, ,` → `,`)
3. **Convert multiple brackets to weights** (e.g., `((girl))` → `(girl:1.21)`)
4. **Add space after punctuation before letters/digits** (e.g., `,text` → `, text`)
5. **Trim spaces adjacent to brackets/parentheses** (e.g., `( girl)` → `(girl)`)
6. **Remove spaces before punctuation marks** (e.g., `word .` → `word.`)
7. **Normalize line breaks and remove empty lines** (e.g., `\n\n` → `\n`)
